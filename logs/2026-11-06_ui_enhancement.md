# 2026-11-06 配网页增强：Captive Portal + WiFi 扫描 + App 导入

## 改动总结

### 1. 配网页完全重做 (wifi_provision_page.c)
- **标签页布局**：手动配置 vs 导入配置
- **手动配置**：
  - WiFi 选择：下拉菜单 + 扫描按钮
  - 手动输入 WiFi 名 (兼容不在扫描范围内的 WiFi)
  - MQTT 字段变为可选 (可先只配 WiFi)
  - 警告弹框如果 MQTT 不完整
- **导入配置**：
  - App 配置字符串粘贴框 (JSON 格式)
  - 手机 WiFi 列表按钮 (占位，真实需 App 支持)
- 提升 UX：toast 消息分 OK/失败两种颜色，按钮反馈立即响应

### 2. 后端新增端点 (wifi_sta.c)
- **GET /api/wifi/scan**：扫描周围 WiFi（目前返回空列表，可扩展）
- **GET /* (Captive Portal)**：兜底所有非配网路由，302 重定向到根目录
  - 浏览器自动检测到 Captive Portal，自动弹页无需手动输 IP

### 3. MQTT 字段改为可选
- 配网时不强制填 MQTT 三元组
- 用户可以先连上 WiFi，再用 App 或回到配网页补充密钥
- NVS 存储 MQTT 字段为空字符串时，mqtt_client_start() 会报错但不影响 WiFi

## 工作流程

**首次快速配网**：
1. 连接热点 → 浏览器自动弹配网页 ✓
2. 点扫描 → 选 WiFi → 输密码 → 保存
3. 设备重启 → 连接 WiFi → 开启应用层 (未连 OneNET 但设备可用)

**补充密码**：
1. App 配网页或设备 AP 回到根目录
2. 填 MQTT 三元组
3. 重启 → 连接 OneNET

**导入配置**：
1. 从 App 复制配置 JSON（含 WiFi+MQTT）
2. 标签页切到导入，粘贴
3. 自动填充所有字段并保存
