# 2026-10-01 开发日志

## 创建所有外设驱动文件

**时间**：2026-10-01 12:55

**操作内容**：
根据 `.cursor/rules/pin-config.md` (引脚配置) 和
`.cursor/rules/peripheral-config.md` (外设配置) 两个说明文件,
为 9 个外设分别新建了独立的子文件夹, 每个子文件夹内包含 `.c/.h`
驱动文件, 并在文件中完成引脚宏定义配置。

**新建的外设驱动**:

| 序号 | 目录 | 外设 | 通信接口 | 主要引脚 |
|------|------|------|----------|----------|
| 1 | `hardware/tft_display/` | 128x160 RGB TFT 显示屏 | SPI (软件/硬件) | GPIO7-12 |
| 2 | `hardware/servo/` | 标准 PWM 舵机 x2 | PWM (LEDC 50Hz) | GPIO13, GPIO14 |
| 3 | `hardware/motor_driver/` | TB6612FNG 双路电机 | PWM (LEDC 20kHz) + 74HC595 方向 | GPIO15, GPIO16 |
| 4 | `hardware/pcf8574/` | PCF8574 IO 扩展 (按键) | I2C | GPIO17, GPIO18, GPIO21 |
| 5 | `hardware/k230_uart/` | K230 AI 视觉模块 | UART1 (115200) | GPIO38, GPIO47 |
| 6 | `hardware/voice_module/` | CI-03T 语音识别 | UART2 (9600) | GPIO39, GPIO40 |
| 7 | `hardware/encoder/` | 增量式编码器 x2 | PCNT | GPIO41/42, GPIO45/46 |
| 8 | `hardware/led/` | SK6812 RGB LED | 74HC595 Q0 | (通过 Q0 控制) |
| 9 | `hardware/magnet/` | 电磁铁 x2 | 74HC595 Q5/Q6 | (通过 Q5/Q6 控制) |

**每个 `.h` 文件包含**:
- 引脚宏定义 (`#define XXX_GPIO`)
- 通信接口配置 (波特率/I2C 地址/分辨率 等)
- 数据类型与枚举定义
- 函数声明 (含 Doxygen 注释: 功能/参数/返回值)

**每个 `.c` 文件包含**:
- ESP-IDF 驱动初始化 (gpio / ledc / spi / i2c / uart / pcnt)
- 引脚/外设安装与配置
- 核心读写函数实现
- ESP_LOG 日志输出

**构建系统更新**:
- 为每个外设目录添加 `CMakeLists.txt` (idf_component_register)
- 已在 `0.1/CMakeLists.txt` 中将 11 个组件目录注册到
  `EXTRA_COMPONENT_DIRS`
- 电机/电磁铁/LED 模块通过 `REQUIRES hc595` 依赖 74HC595 驱动

**已有外设 (无需重复创建)**:
- `hardware/mpu9250/` - MPU9250 IMU (完整代码)
- `hardware/hc595/` - 74HC595 移位寄存器 (完整代码)

**注意事项**:
1. SK6812 RGB LED 通过 74HC595 Q0 控制, 但 SK6812 需要单线归零码
   协议 (~100ns 精度), 无法仅靠 74HC595 普通 IO 翻转实现完整 RGB 控制。
   当前 `led.c` 仅做开关控制 (颜色值取 RGB 最大分量判断亮灭),
   完整 RGB 时序需要后续改用 ESP32 RMT 外设 + 独立 GPIO。
2. `pcf8574.c` 中按键事件回调已声明, 中断服务注册接口已提供,
   实际消抖/事件分发需后续任务实现。
3. `k230_uart.c` 帧格式 (`HEAD=0xAA, TAIL=0x55`) 为临时定义,
   需根据实际 K230 协议调整。
4. `tft_display.c` 初始化序列按 ST7735 示例编写,
   若实际驱动为 ST7789, 需调整命令序列。

**下一步**:
- 等待用户确认各外设初始化流程
- 后续在 `main/main.c` 中按优先级顺序初始化各外设
- 根据实际硬件测试并修正引脚配置

## 配置 PlatformIO 国内镜像加速

**时间**：2026-10-01 13:15

**操作内容**：
通过测速选择了最优的国内镜像源，并完成 PlatformIO Core 6.2.0
的安装与配置。

**测速结果 (PyPI 镜像下载 platformio 包元数据)**：

| 镜像源 | 速度 | 排名 |
|--------|------|------|
| 清华 (pypi.tuna.tsinghua.edu.cn) | **102 KB/s** | 🥇 |
| 腾讯 (mirrors.cloud.tencent.com) | 91 KB/s | 🥈 |

| 阿里云 (mirrors.aliyun.com) | 74 KB/s | 4 |
| 豆瓣 (pypi.doubanio.com) | 50 KB/s | 5 |

**完成的配置**：

1. **pip 全局清华源** — `~/.config/pip/pip.conf`
   ```
   global.index-url = https://pypi.tuna.tsinghua.edu.cn/simple
   global.trusted-host = pypi.tuna.tsinghua.edu.cn
   ```

2. **PlatformIO Core 安装** — `pip3 install -U platformio`
   - 安装位置：`/Users/m/Library/Python/3.9/bin/`
   - 版本：PlatformIO Core 6.2.0

3. **PlatformIO 二进制镜像环境变量** — `~/.platformio/env.sh`
   - `PLATFORMIO_GIT_URL=https://gitee.com/EspressifSystems/platformio-espressif32.git`
     （Gitee 镜像加速 espressif32 平台 git 克隆）
   - `PLATFORMIO_PKGS_URL=https://registry.npmmirror.com/-/binary/platformio`
   - `PLATFORMIO_PLATFORMS_URL=...platforms`
   - `PLATFORMIO_TOOLS_URL=...tools`
   - `PLATFORMIO_PACKAGES_URL=...packages`
     （npmmirror 镜像加速 platformio 二进制包下载）

4. **PATH 与自动加载** — `~/.zshrc`
   ```
   export PATH="$HOME/Library/Python/3.9/bin:$PATH"
   [ -f "$HOME/.platformio/env.sh" ] && source "$HOME/.platformio/env.sh"
   ```

**验证结果**：
- `pio --version` → PlatformIO Core 6.2.0 ✓
- `pio platform list` → espressif32 @ 6.13.0 已安装 ✓
- `pio platform list` → espressif32 @ 6.5.0 已安装 ✓
  （满足 `platformio.ini` 的 `platform = espressif32` 要求）
- 镜像环境变量已正确加载 ✓

**注意事项**：
1. `urllib3 v2` 警告（macOS Python 3.9 用的 LibreSSL）不影响功能。
2. 之前 `~/.platformio/penv`（PlatformIO 6.1.19）仍存在，但已被新装的
   `/Users/m/Library/Python/3.9/bin/pio` 覆盖。可在 `~/.zshrc` 中调整
   PATH 顺序，旧版被新 PATH 优先。
3. VSCode 终端需重新打开（或 `source ~/.zshrc`）才能加载新 PATH。
