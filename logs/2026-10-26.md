### 遇到的问题 / 注意点

- **为什么版本号从 0.22 直接跳到 0.30**: 用户明确要求迭代到 0.30, 按规则照办。
  规则里"版本号数字递增"是总的约定, 具体数字由用户定。
- **0.30 是第一个包含平衡控制修复的正式发布版本**: `v0.22` 这个 tag/release 是在
  "D 项符号 / 电机方向 / 配平表"那批修复**之前**打的, 所以 GitHub 上下载到的 0.22
  是不含这些修复的。0.30 把它们一并发布。
- **本地 0.21 目录删除**: 按"本地只保留最新两版"的既有做法。历史代码仍在 git 历史里
  (`git checkout v0.21`), GitHub 上的旧 release / tag 一个没删。
