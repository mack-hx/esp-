# 2026-10-15 开发日志

## 一、背景 (上下文)
用户改了一下平衡车腿部四连杆结构 ——
之前装反了辅助轴在主轴的下前方, 导致重心前倾,
水平时俯仰角会倾斜 30° 左右。
现在改到后上方, 平衡时俯仰角基本在水平面。
(此改动 1.4 硬件 + mpu9250 标定都未动, 仅机械结构)

但新结构下:
- 30° 仍然对应腿"伸展"位
- 100° 不能让腿"完全蜷缩"
- 完全收腿 / 完全伸腿的具体角度还不知道, 需要测

## 二、舵机行程确认 (本轮最终值)
**实测完全收腿角度: 120°**
实测伸腿角度: 30° (之前已知)

### 本轮所有改动

#### 1. `servo.h`: 舵机限位收紧
```c
#define SERVO_LIMIT_MIN     30
#define SERVO_LIMIT_MAX     120   // 原 100→180→120
#define SERVO_DEFAULT_ANGLE 80
```

#### 2. `mpu9250.c`: PITCH_ZERO_REF = 90
```c
// 实测: 水平位 az≈1, ay≈0 → atan2(1,0)=90°
#define PITCH_ZERO_REF   90.0f    // 平衡时 pitch ≈ 0
```
烧录后水平放置, MPU 页 pitch 应该显示接近 0。

#### 3. `servo.h`: 默认角度调高
```c
#define SERVO_DEFAULT_ANGLE 100   // 原 80, 用户觉得默认位置偏高
```

#### 3. `trim.c/h`: 新增 `trim_erase_nvs()`
```c
esp_err_t trim_erase_nvs(void);  // 擦 NVS trim namespace
```
`balance_init()` 中, `trim_load()` 前调用一次, 丢弃旧结构下的所有配平点。

#### 4. `ui_servo.c`: 显示更新
```c
"Range 30-100" → "Range 30-120"
```

#### 5. `param.c`: SERVO_CENTER 范围更新
```c
PARAM_SERVO_CENTER: min=30, max=100 → min=30, max=120
```
