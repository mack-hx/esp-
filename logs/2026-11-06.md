
## 21:30 配网页 + BLE 配置导入 (0.45)

### 三个核心改进

#### 1. Captive Portal DNS 劫持 (自动弹网页)
- `wifi_sta.c` 新增 DNS 服务器: 所有 DNS 查询 → 192.168.4.1
- 手机连接 AP 后，浏览器自动检测到 Captive Portal 并跳配网页
- DNS 劫持在 AP 启动时开启，STA 连上后关闭

#### 2. WiFi 扫描修复
- AP 改为 AP+STA 混合模式 (原来纯 AP 无法扫描)
- 扫描端点 `/api/wifi/scan` 实现真实 WiFi 列表
- 返回周围 WiFi 的 SSID、信号强度、频道

#### 3. App 配置导入通道
- **新 HTTP 端点**: `/api/cfg/get` 返回 ESP32 已保存的 WiFi+MQTT 配置
- **新 BLE 指令**:
  - `CFGW:{"ssid":"...","pass":"..."}` - WiFi 配置 (重启后生效)
  - `CFGM:{"pid":"...","dev":"...","ak":"..."}` - MQTT 配置 (重启后生效)
- **App 按钮**: "发送配置到主车/副车" (BLE 连接时可用)
  - 配网页也新增 "App导入" 按钮 (调用 `/api/cfg/get`)

### 实现细节
- DNS: 极简 UDP 服务器，兼容 lwIP，答复所有查询为 192.168.4.1
- WiFi: `wifi_sta_save_credentials()` 公开 API 供 BLE/HTTP 调用
- BLE: `ble_handle_cmd()` 支持新指令格式，JSON 极简解析
- HTTP: 新增 POST 参数裁剪 (trim)，JSON 数据库解析
- App: Vue 新增 `onSendToBLE(which)` 方法，通过 BLE 发 JSON 配置

### 编译状态
- 主车 0.45: ✓ 编译通过 (RAM 32.7% / Flash 33.0%)
- 副车: ⚠️ 系统 CMake 错误 (xcrun 架构问题, 非代码问题)

### 工作流程
**快速配网**:
1. 手机连接 `BalanceRobot_Setup_XXYY`
2. 自动打开配网页 (DNS 劫持)
3. 点"扫描WiFi" → 选择家里 WiFi
4. 或点"App导入" → 从 App 读取配置
5. 填密码 → "保存"
6. 设备重启，进 STA 模式

**从 App 发送配置**:
1. App 连接蓝牙 (直控模式)
2. 设置 OneNet 三元组
3. 点"发送配置到主车" → 蓝牙发 CFGM 指令
4. 设备重启，配置生效
