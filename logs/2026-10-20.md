## 2026-10-20 灯控制功能

**操作内容**：
1. 创建 `app/common/mqtt_client.js` - MQTT WebSocket 客户端
   - 使用 WebSocket 连接 OneNet MQTT Broker (studio-mqtt.heclouds.com:1883)
   - 实现 MQTT 3.1.1 协议 (CONNECT/CONNACK/PUBLISH/SUBSCRIBE/PING 等)
   - 提供 `mqttConnect()` / `mqttDisconnect()` / `mqttPublishLedControl()` 等 API

2. 修改 `user/onenet_client/onenet_client.c` - 添加灯控制属性处理
   - 添加 `#include "led.h"` 头文件
   - 添加 `json_find_value_bool()` 和 `json_find_value_int()` 辅助函数
   - 添加 `handle_led_control()` 函数处理灯控制属性
   - 支持的属性：
     - `led_on`: bool - 灯开关
     - `led_color`: int - RGB 颜色值 (0x00RRGGBB)
     - `led_brightness`: int - 亮度 (0-255)
     - `led_preset`: int - 预设颜色 (0=关,1=红,2=绿,3=蓝,4=黄,5=青,6=紫,7=白)

3. 修改 `app/pages/connect/connect.vue` - 添加灯控制 UI
   - 灯开关控制 (switch)
   - 预设颜色按钮 (8种颜色)
   - 自定义 RGB 滑块
   - 亮度控制滑块
   - 颜色预览
   - 发送灯控制按钮

**使用方式**：
1. 烧录 ESP32 最新固件 (包含灯控制处理)
2. 打开 App → 设备连接页面
3. 填写 OneNet 配置，点击"连接 MQTT"
4. 连接成功后，使用灯控制卡片进行控制
5. 点击"发送灯控制"将指令通过 MQTT 发送到 ESP32

**MQTT Topic**：
- 发布: `$sys/{productId}/{deviceName}/thing/property/set`
- Payload: `{"params":{"led_on":{"value":true,"time":...}}}`

## 2026-10-20 舵机角度控制 + App 控制页 UI 调整

**操作内容**：

1. **ESP32 侧** - 修改 `user/onenet_client/onenet_client.c`
   - 添加 `#include "servo.h"` 头文件
   - 添加 `handle_servo_control()` 函数处理舵机角度属性
   - 支持的属性：
     - `servo1_angle`: int - 舵机1角度 (30-120)
     - `servo2_angle`: int - 舵机2角度 (30-120)
   - 在 `handle_property_set()` 中调用 `handle_servo_control()`
   - 通过 `servo_set_angle(SERVO_1/SERVO_2, angle)` 控制对应舵机

2. **App 侧** - 修改 `app/pages/control/control.vue`
   - 将 急停/起立/配平 按钮移至 pad-card 顶部
   - 简化方向十字键：左/右转在中间行居中，上/下前进后退缩小为辅助按钮
   - 新增舵机控制区块：
     - 滑动条：范围 30-120°，步进 1°，默认值 100°（与 ESP32 `servo.h` 同步：`SERVO_LIMIT_MIN=30`, `SERVO_LIMIT_MAX=120`, `SERVO_DEFAULT_ANGLE=100`）
     - 滑动条下方三个按钮：◀ 左（设置舵机1）、◈ 双（设置两路）、右 ▶（设置舵机2）
     - 拖动滑动条实时预览角度，按下按钮后发送 `servo1_angle` / `servo2_angle` 到 ESP32

3. **App 侧** - 修改 `app/utils/control.js`
   - 新增 `setServoAngle(servoId, angle)` 方法
   - servoId: 0=舵机1, 1=舵机2, 2=同时设置两路
   - 内部调用 `setDesiredProperty({ servo1_angle: angle, servo2_angle: angle })`

**使用方式**：
1. 烧录 ESP32 最新固件
2. 打开 App → 控制页面
3. 拖动舵机角度滑动条调整角度
4. 点击 左/双/右 将当前角度下发到对应舵机

**备注**：
- 编译验证受阻于 macOS CommandLineTools x86_64/arm64 架构冲突（`xcrun` 无法加载），为预存在环境问题，与代码修改无关
