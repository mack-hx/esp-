# ESP32-S3R8N8 平衡轮腿机器人 - 版本 1.1

## 1.1 相对 1.0 改了什么（一句话）

**腿角补偿从「量腿高 + 左右分腿 + 线性兜底 + Kp 调度」四层，
砍成一张一维表：舵机角 → 扶到平衡时的俯仰角。不量任何腿长。**

```
1.0:  舵机角 → [你拿尺子量"电机↔舵机轴心直距"] → 查表 → 补偿
     + 左右两条腿各一张表（要拆腿，分两次采）
     + 查表不可用时退回线性 leg_k
     + Kp 按腿高调度（kp_hslope / kp_href）

1.1:  舵机角 → [你用手把车身扶到接近平衡] → 读 Pitch → 记下来 → 补偿
     一张表，不用尺子，不用拆腿，一次采完
```

为什么能砍掉腿高：**控制器只关心"这个腿角对应的平衡姿态是多少度"，
腿高只是这个答案的中间变量，不是必要输入。**

## 驱动方式：双轮同向（不是差速）

平衡靠两轮**一起**朝倒的方向跑，用轮子的牵引力把重心甩到轮轴上方 ——
标准 inverted-pendulum-on-wheels 平衡车做法。

差速只能让车**原地转**，产生不了托住重心所需的平移加速度，扶不住倒下的车身。
方向搞反了不用重烧固件：网页上把 `bal_sign` 从 `+1` 改成 `-1` 即可。

## 控制结构

```
速度环 (外环, 慢)  ──> 目标倾角 target_pitch (°)
     │
     ▼
平衡环 (内环, 快)  ──> 电机输出 (%)  ──> 两轮同向

输入: MPU9250 姿态角/角速度 + 编码器轮速
输出: 电机 A/B PWM (两轮同向) + 两路舵机
```

**控制周期 10ms 单环串级**，用 `vTaskDelayUntil` 保证周期稳定，
PID 用实测 dt（网页 `/api/status` 的 `dt_ms` 可以验证，应该稳在 ~10）。

> 没有转向环了。1.0 里那三个 `steer_*` 参数输出恒为 0，纯占位，
> 留着只会让人以为能调。要做转向时再加。

## 姿态读数的修正链

这是 1.1 的核心，在采样阶段做：

```
pitch_修正 = pitch_原始 + ang_zero − trim_pitch(舵机角, 舵机中心角)
```

| 项 | 管什么 |
|---|---|
| `ang_zero` | MPU 焊歪了多少度（固定偏差） |
| `trim_pitch` | 腿弯到这个角度时，平衡姿态本身就不是铅垂 |

**为什么在信号侧减，不加在目标倾角上**：这样摔倒判定（`|pitch| > ang_limit`）
也跟着被修正，否则腿弯多了会误判摔倒。

## 配平标定（先做这个，不标定站不起来）

**物理含义**：腿拨到某个角度 → **你用手把车身扶到接近平衡** → 读 Pitch → 记下来。
攒够几个点，控制器就知道"腿在 X 度时我该盯多少度"。

**怎么标（30 秒一个点）**：

1. 把车**扶住**（放桌上 / 夹具 / 手扶）。电机全程刹车，不会自己跑
2. 网页展开「① 配平标定」面板
3. 滑块拨到 30°，点「**① 拨腿到这里**」
4. **用手把车身扶到接近平衡**（车往哪边倒就往另一边扶），稳住
5. 点「**② 记下这个角度**」
6. 换角度重复：40 / 50 / 60 / 70 / 80 / 90 / 100（**6~8 个点够了**）
7. 点顶部「**保存到 NVS**」才落盘

网页会实时显示已录点数、俯仰角跨度，以及是否已生效。

**几个设计决定：**

- **为什么不用腿高**：测"轮心离地高度"时车一动高度就变，数据没法用。
  1.0 改测"电机中心↔舵机轴心直距"虽然稳，但要拿尺子量、
  还得拆腿分左右两次采。1.1 直接测最终要的量，一步到位。
- **为什么一张表不分左右**：两路舵机镜像同动，扶到平衡时左右差异
  **已经包含在测出来的那个 Pitch 里了**，不需要再拆开。
- **越界夹端点不外推**：舵机角超出标定范围时，机构可能已到死点，
  曲线形状完全变了，外推出来的值是编的。夹到端点则补偿幅值始终有界，
  越界不会突变。
- **点数 < 2 或俯仰角跨度 < 0.05° 时不做补偿**：这是"没标定也能安全跑"
  的保证，行为退回到只用 `ang_zero`。

> 舵机是**开环**的（只写 PWM，无位置回读），表里的横轴是"指令角"不是"实际角"，
> 腿受力变形会造成偏差。但这是个**前馈平移量**，常值残差由平衡环的 Ki 兜住，
> 不需要精确模型。

详细原理和踩坑见 `../logs/2026-10-05.md`。

## 状态机

```
IDLE ──(启动)──> STANDBY ──(连续稳定 500ms)──> BALANCING
                                          │
                                     (倾角超限)
                                          ▼
                                       FALLEN
                                          │
                                    (人把车扶正)
                                          ▼
                                       STANDBY
```

- **IDLE**：未启动，电机刹车
- **STANDBY**：已启动但还没进平衡（等姿态连续稳定 = 启动门控）
- **BALANCING**：控制中
- **FALLEN**：判定摔倒，电机已停、积分已清，**等扶正后自动回 STANDBY**

**启动门控**：必须连续满足 `|pitch| < arm_pitch` 且 `|角速度| < arm_rate`
达 `arm_time` 毫秒才放行。原因是"没超限"和"稳得住"完全是两回事 ——
被扶着还在晃就放行，电机一接手晃得更厉害，直接摔。

**摔倒判定**：`|pitch| > ang_limit`（默认 25°）。宁可误停也不能不停。

## 硬件映射（沿用 0.2，未改动）

编号统一为「物理左 = 1，物理右 = 2」。

| 实物位置 | 编码器 | 电机 | 舵机 |
|---|---|---|---|
| 左 | `ENCODER_1` = GPIO45/46 | `MOTOR_A` = PWMA (GPIO15) | `SERVO_1` = GPIO14 |
| 右 | `ENCODER_2` = GPIO41/42 | `MOTOR_B` = PWMB (GPIO16) | `SERVO_2` = GPIO13 |

## 屏上平衡控制页

菜单第 1 项。显示状态机状态 + 串级各环中间量：

```
BALANCE CTRL
St:  IDLE OFF
Pit:  -0.15 g   1.2
Tgt:   0.00 deg
Bal:   0.0 %
Mot: A   +0 B   +0
Whl:   0.0 T 0.00
------------------------------
[K1]Bk [K2]On/Off
[K3]E-Stop (clr int)
```

K2 启停，K3 急停（清积分），K1 回菜单。进入/退出该页都会自动停机。
