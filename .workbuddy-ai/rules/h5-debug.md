# H5 调试

## 前置条件

- 由用户在 HBuilderX 里运行: 运行 → 运行到浏览器 → Chrome
- 地址 `http://127.0.0.1:8080/`
- 动手前先确认服务在跑: `lsof -i :8080`; 有 node 进程监听 = 正常, 无输出 = 未启动

## 流程

1. 确认端口: `lsof -i :8080`
2. 改 `.vue` 文件并保存, HBuilderX 自动编译热更新, 不需要重启服务
3. 刷新页面: 重新打开 `http://127.0.0.1:8080/`, 或用浏览器自动化能力执行 reload
4. 验证: 抓页面结构 (DOM/文本) + 截图, 对照改动确认视觉与布局
5. 改了没生效: 让用户 `Cmd+Shift+R` 强刷 (缓存), 或确认 HBuilderX 编译无报错

## 浏览器侧操作

用当前 harness 的浏览器自动化能力 (Playwright / 内置浏览器预览), 常用动作:

| 目的 | 做法 |
|------|------|
| 打开/刷新页面 | 导航到 `http://127.0.0.1:8080/` |
| 取页面元素结构 | 抓快照 / 读 DOM 文本 |
| 看视觉效果 | 截图 |
| 点按交互 | 定位元素后点击, 再抓快照确认状态 |

## 示例: 改 DPad 布局

1. 改 `app/pages/control/control.vue`
2. `lsof -i :8080` 确认服务在跑
3. 刷新页面
4. 截图 + 快照验证布局
