# ESP32 平衡轮腿机器人（可分离双车）

一台用 ESP32-S3 做的双轮自平衡机器人：两条"腿"的长度由舵机调节，可以蹲下、起立、跟着节拍跳舞；主车和副车能各自运行，也能磁吸对接合成一台车。整个工程从底层驱动、控制算法、LCD 界面到手机 App 都是自己写的，可直接编译烧录复现。

> 状态：v0.43 已发布（编译 / 离线测试通过），**最新控制参数仍在真机调试中**，欢迎参考思路，但不要指望开箱即稳。

## 功能特性

**运动与控制**

- **双轮自平衡**：串级 PID 与 LQR 两套控制律可切换，静止时能稳住，被推后自动回位。
- **LQR 位置保持**：状态反馈（倾角 / 角速度 / 位置 / 速度），回位速度按 `sqrt(2·a·Δx)` 限速，积分只在近位累积，避免远距离猛冲。
- **轮腿姿态**：左右两路舵机对称调节腿长，支持蹲下 / 起立 / 按 1 Hz 节拍跳舞，起立带软启动。
- **横滚补偿**：检测左右高度差地形，自动调整两腿长度（默认关闭，待实车验证）。
- **原地转向与速度档位**：4 档直驱（20/40/60/80% PWM），带起动死区补偿。

**交互**

- **1.8" TFT 屏 + 4 个按键**：主页显示倾角、轮速、位置、Roll、连接状态；菜单可进平衡、编码器、舵机、IMU、灯 / 电磁铁、网络状态等子页。
- **SK6812 状态灯**：按车体状态自动配色（摔倒红 / 舵机粉 / 合体蓝 / 未对齐红 / 对接近黄闪 / 站立绿 / 未站立黄），App 手动设色后被锁定。
- **手机 App（uni-app）**：遥控、急停、起立、配平、参数滑块、状态页，以及独立的姿态页。
- **BLE 直控**：GATT `0xFFE0/0xFFE1`，ASCII 文本指令，50 ms 回传一次俯仰角，断开或指令超时自动归零（不关平衡）。

**双车与联网**

- **双车对接**：电磁铁吸合 + 微动开关检测，合体后主车接管两车指令。
- **OneNET 物模型（MQTT）**：属性上报、期望值下发、服务调用，App 走 HTTPS 开放接口。
- **参数在线调整**：24 项参数在 App 上拖动即生效，掉电不丢（NVS 保存）。

**调试**

- **脱机记录**：车离开平衡态时把最近 40 s 的采样（倾角 / 轮速 / 位置 / Roll / 输出）写进 flash，断电不丢，插线读出 CSV。
- **在线抓包**：串口实时抓取数据并生成 CSV，配套 Python 分析脚本（时域 / FFT）。

## 硬件清单

| 部件 | 型号 / 规格 | 接口与引脚 |
| --- | --- | --- |
| 主控 | ESP32-S3R8N8（8 MB PSRAM / 8 MB Flash） | — |
| IMU | MPU9250 | I2C，SCL 1 / SDA 2 |
| 编码器 | 增量式正交，11 线 × 4 倍频 → 44 计数/转 | PCNT，左 45/46，右 41/42 |
| 电机 | 直流减速电机 ×2 | PWM A 15 / B 16（20 kHz，10 bit） |
| 电机驱动 | TB6612FNG | 方向由 74HC595 给出 |
| 方向扩展 | 74HC595 | SCLK 5 / RCLK 4 / DS 6 |
| 舵机 | 两路（默认镜像） | LEDC 50 Hz，14 / 13 |
| 显示 | 128×160 RGB TFT（ST7735/ST7789，横屏） | SCL 7 / SDA 8 / DC 10 / CS 11 / 背光 12 |
| 按键 | PCF8574 扩展，4 个按键 + 2 个微动开关 | I2C，SCL 17 / SDA 18 / INT 21 |
| 状态灯 | SK6812 RGB ×2 | 数据 9 |
| 电磁铁 | 74HC595 驱动 | 复用方向扩展芯片 |

引脚定义都写在各外设的 `hardware/*/xxx.h` 顶部，改硬件只需改这些宏。

## 软件架构

```
0.44/
├── main_car/                 # 主车固件 (ESP-IDF + PlatformIO)
│   ├── main/                 # 入口、任务创建
│   ├── hardware/             # 外设驱动，每外设一个子文件夹
│   │   ├── mpu9250/          #   IMU 初始化、量程、bypass 磁力计
│   │   ├── encoder/          #   PCNT 正交解码
│   │   ├── motor_driver/     #   TB6612 PWM + 死区补偿
│   │   ├── servo/            #   舵机角度 / 腿长表
│   │   ├── hc595/ pcf8574/   #   方向扩展、按键
│   │   ├── tft_display/      #   LCD 驱动
│   │   ├── led/ magnet/      #   状态灯、电磁铁
│   │   └── wifi_sta/         #   Wi-Fi 连接
│   ├── user/                 # 应用层
│   │   ├── pid/              #   PID 与 LQR 控制律
│   │   ├── control/          #   姿态、舵机、遥控指令分发
│   │   ├── odom/             #   位置 / 速度里程计
│   │   ├── param/            #   参数表、NVS 存取、版本校验
│   │   ├── ui/               #   LCD 各页面
│   │   ├── trim/             #   传感器零点配平
│   │   ├── trace/            #   脱机 / 在线记录
│   │   ├── ble_ctrl/         #   BLE 直控
│   │   ├── onenet_client/    #   MQTT 物模型
│   │   └── status_led/       #   状态灯配色规则
│   ├── lib/                  # 第三方库（LCD、SK6812 等）
│   └── version.txt           # 固件版本（编译时写入）
├── sub_car/                  # 副车固件（结构同主车，功能裁剪）
├── app/                      # 手机 App（uni-app / Vue3）
└── test/                     # PC 端 gcc 离线单元测试
```

**控制流程**：IMU 采样 → 互补滤波得 pitch/roll → 编码器算轮速与位置 → 平衡环（PID 或 LQR）算出 PWM → 电机驱动；外层串级：位置环 → 速度环 → 平衡环，倾角限幅 8° / 7° / 35°。

**任务划分**：控制任务是实时主循环（IMU 采样 + 控制 + 电机输出），UI、BLE、MQTT、记录各自独立任务，参数通过互斥保护的结构体共享。

## 快速开始

### 1. 环境准备

- [PlatformIO](https://platformio.org/)（VS Code 插件或 CLI），首次编译会自动拉取 ESP-IDF
- Python 3（跑辅助脚本）
- 手机 App：HBuilderX，或直接用手机浏览器打开 H5 版本

### 2. 编译与烧录

```bash
cd 0.44/main_car
pio run                  # 编译
pio run --target upload  # 烧录
pio device monitor       # 串口查看日志
```

> 改了 `version.txt` 之后必须 `pio run -t fullclean` 再编译，否则固件里还是旧版本字符串。

### 3. 离线测试

不需要硬件，PC 上直接跑控制逻辑和参数表校验：

```bash
scripts/run_tests.sh 0.44        # 全部离线测试
scripts/check_param_sync.py 0.44 # 车端与 App 参数表逐项比对
```

### 4. App

```bash
# 方式一：HBuilderX 打开 0.44/app → 运行到手机 → Android
# 方式二：打包 H5 后浏览器访问
```

App 首次启动需要在连接页填写 OneNET 三元组（产品 ID / 设备名 / 设备级 AccessKey），然后点验证。**仓库里现存的 AccessKey 是作者测试设备的，请换成你自己在 OneNET 控制台创建的产品**。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 起立 / 蹲下 | App 遥控页按钮，或 LCD 菜单 |
| 前后移动 | App 摇杆、BLE 指令或 LCD 档位 |
| 急停 | App 急停按钮；LCD 对应按键 |
| 配平（零点标定） | App 配平按钮，同时标定 pitch 与 roll 零点，存入 NVS |
| 改参数 | App 参数页滑块，实时下发，掉电保存 |
| 看数据 | LCD 主页 / 状态页，或串口日志 |

## 通信协议

**BLE 直控**（连接设备名 `BalanceDog`）

| 方向 | 内容 | 含义 |
| --- | --- | --- |
| App → 车 | `M:<v>` | 移动指令，v 为编码后的方向 / 速度 |
| App → 车 | `STOP` | 急停 |
| App → 车 | `STAND` | 起立 |
| 车 → App | `P:<pitch>` | 俯仰角，50 ms 一帧 |

非零移动指令 600 ms 未刷新或蓝牙断开时自动归零。

**OneNET 物模型**：属性（pitch、roll、轮速、位置、状态、连接信息等）由车端上报；期望值（参数、指令）由平台下发；`call-service` 触发急停、配平、姿态等动作。物模型说明见 `0.44/app/onenet_物模型.md`。

## 已知限制

- 最新参数（LQR 增益、速度环、死区）与部分新功能**尚未完成真机验证**。
- 轮速因机械放大与标称值有偏差（实测约 2.7 倍），相关增益仍在重调。
- Wi-Fi 与 BLE 同开时，BLE 通知周期可能抖动。
- 副车功能是主车的裁剪版，App 侧切换逻辑尚不完整。
