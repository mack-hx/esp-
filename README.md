# ESP32 平衡轮腿可分离机械狗

基于 ESP32-S3R8N8 的平衡轮腿机械狗项目。

## 硬件配置

- **主控**：ESP32-S3R8N8
- **PSRAM**：8MB Octal SPI
- **Flash**：8MB
- **开发框架**：ESP-IDF (PlatformIO)

## 项目结构

```
project_root/
├── 0.41/              # 当前版本 (继续改)
│   ├── main/         # 入口
│   ├── hardware/     # 硬件外设驱动（每个外设独立子文件夹）
│   ├── user/         # 用户应用代码 (控制算法 / 参数 / 配平 / OneNet 客户端 / 屏 UI)
│   ├── app/          # 配套 App (uni-app, H5)
│   ├── test/         # 离线单元测试
│   └── docs/         # 版本文档
├── 0.40/             # 上一版本 (LQR 位置保持, 不再修改, 回滚基线)
├── logs/             # 开发日志（按日期组织，本地只保留最近 3 天）
├── releases/         # 打包好的发布版本（只保留最新两版）
└── .cursor/rules/    # 项目开发规则
```

每个版本目录自带完整的 `hardware/ user/ app/`，互不依赖。

## 版本管理

- 版本号数字递增（0.01, 0.02, 0.1, 0.11 …），**仅在用户明确要求时才做版本迭代**
- **不使用 1 以上的版本号**（项目还没正式实现，1 以上不规范）
- 历史版本不得修改，仅供参考和回滚
- 所有新功能在最新版本中开发
- 本地只保留最新两版，旧版目录和 release 打包都删掉（历史代码仍在 git 历史里）

## 开发日志

所有开发过程记录在 `logs/` 文件夹，按日期组织（`logs/YYYY-MM-DD.md`）。

**日志保留策略**：
- **本地只保留最近 3 天**的日志文件
- 超过 3 天的日志**先推送到 GitHub 再从本地删除**（历史代码仍在 git 历史里，需要时可从 GitHub 取回）
- 日常读日志**只看最近 1~2 天**，更早的按需由用户指定再取
- 版本级变更说明放在 `releases/RELEASE_NOTES.md`
