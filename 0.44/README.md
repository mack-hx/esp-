# ESP32 平衡轮腿机械狗 v0.44

ESP32-S3R8N8 双轮自平衡机器人，支持 LQR 位置保持、在线参数调整、蓝牙直控、双车对接。

## 目录结构

```
0.44/
├── main_car/          # 主车固件 (ESP32-S3)
├── sub_car/           # 副车固件 (ESP32-S3)
├── app/               # HBuilderX App (uniapp)
└── test/              # 离线单元测试 (PC 端 gcc)
```

## 快速开始

### 固件编译
```bash
cd 0.44/main_car
pio run                 # 编译
pio run -t upload       # 烧录
```

### 测试验证
```bash
scripts/run_tests.sh 0.43        # 运行所有离线测试
scripts/check_param_sync.py 0.43 # 检查参数表同步
```

### App 打包
1. HBuilderX 打开 `0.44/app`
2. 运行 → 运行到手机或模拟器 → Android
3. 发行 → 原生 App-云打包

## 主要功能

- **LQR 位置保持**: 状态反馈控制，推车后自动回位
- **姿态控制**: App 蹲下 / 起立 / 跳舞，独立姿态页可调跳舞频率
- **横滚角补偿**: 左右高度差地形下自动调整两腿长度（默认关闭，待实测）
- **状态灯**: SK6812 按车体状态自动配色，手动设色后保持
- **参数在线调整**: App 滑块实时下发，无需重烧
- **蓝牙直控**: 低延迟移动控制，pitch 实时推送
- **双车对接**: 主副车合体，对接检测 + 合体模式
- **脱机记录**: flash 存储最近 40 秒数据，摔倒后读出

## 硬件配置

- 主控: ESP32-S3R8N8 (8MB PSRAM / 8MB Flash)
- IMU: MPU9250
- 编码器: AB 相增量式 (44 线)
- 电机驱动: TB6612
- 舵机: 两路同步 (默认镜像)
- 显示: TFT LCD 128×160
- 按键: PCF8574 (4 个按键 + 2 个微动开关)
- LED: SK6812 RGB (2 个)
- 电磁铁: 74HC595 驱动 (对接用)

## 物联网接入

- OneNET 物模型（MQTT）
- 设备: balancing_dog (主车) / balancing_dog_sub (副车)
- 产品 ID: 6YlUqr9lue
