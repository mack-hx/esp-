# Release Notes

## v0.46 (2026-11-10)

**代码清理版 + 平衡环整定**

- 俯仰角改二元解算 `atan2(ay, √(ax²+az²))`，斜前方倾斜时 roll 不再耦合进 pitch
- `lqr_kd` 参数化（App 可调），`PARAM_DATA_VERSION` 39 → 46
- **删掉陀螺陷波**：自激主频跟着陷波裙边走（15Hz 陷波 → 抖在 10.5Hz；11Hz 陷波 → 抖在 8Hz），
  说明不是固定结构模态，而是陷波相位滞后在环路里造出的不稳定。陀螺只留一阶低通
- `lqr_kd` 默认 1.5 → 0.9（PC 离线测试扫 ±30% 增益 / ±5ms 延迟取最优）
- 蹲姿增益拆成 P / D 两路：P ×0.55（保刚度）、D ×0.50（防自激）
- 位置环试过「直接输出电机分量」结构，刹车会把车刹翻，已整体回退串级结构
- 修复蓝牙 `ble_gatts_start()` 漏调导致连不上；OneNET `param_get` 应答 topic 改 `invoke_reply`
- 修复 PC 端 `test_lqr_pc.c` 缺 `param_get_float` 桩

## v0.44 (2026-11-05)

**坡道保持 + 横滚闭环 + 偏航阻尼 + 参数表瘦身**

### 主要改进

#### 1. 坡上站得住、爬得动
- `lqr_pos_integral()` 新增「正在远离锚点」判定：溜坡时即使速度超阈值也继续累积积分，不再越溜越没劲
- `LQR_POS_I_MAX` 5→12°、`LQR_POS_I_BAND` 6→8 cm
- 新增坡度前馈 `SLOPE_FF_K=0.35`：行走时把 1.5 s 低通后的倾角按比例补进目标（限 ±3°），上坡多前倾、下坡多后仰
- 速度环倾角上限 7→10°（`SPD_PID_WALK_PITCH_MAX`）

#### 2. 横滚闭环（代替查表开环）
- `hardware/roll_compensator` 改为 IMU 横滚 PD + 弱积分，输出左右舵机角偏置
- 实测灵敏度 0.14 °横滚/°舵机，Kp 2.0 / Ki 0.4 / Kd 0.10，限 ±15°，抬起 30°/s、收回 12°/s
- 死区内积分 3 s 泄放；输出无响应看门狗（>3° 且横滚变化 <2°/s 持续 0.6 s 冻结积分）
- `servo_set_roll_trim()` 在写硬件时叠加，不改逻辑目标角

#### 3. 偏航阻尼（走直线）
- 航向角速度取陀螺 **Y 轴**（车体竖直轴）低通后反馈进差速环：`目标差速 − 0.40·yaw_rate`
- 死区 10°/s、限幅 ±4 rpm，避免编码器噪声与单侧悬空打滑时越拱越快

#### 4. 配平与显示
- 配平同时标定 pitch / roll 零点，采零点前先复位横滚补偿
- `s_data.roll` 与舵机补偿同源（扣零点），LCD 平衡页新增 `Rol:` 与 `Svo: S1/S2` 行

#### 5. 参数表瘦身（版本 38 → 39，24 → 18 项）
- 删除 LQR 上线后从不生效的 `bal_kp / bal_ki / bal_kd` 与 `pos_kp / pos_kd / pos_ki`
- 删除串级 PID 死分支：`balance_pid.c/h`、`position_pid.c/h`；`POS_PID_LEAN_MAX` 迁至 `lqr.h` 的 `LQR_LEAN_MAX`
- 输出限幅由三层 clamp 合并为一层
- App `paramDef.js` 同步删除 6 项、id 重排、`PARAM_VER` 39

## v0.43 (2026-11-02)

**姿态控制 + 横滚角补偿 + 状态灯**

### 主要改进

#### 1. App 姿态控制
- **遥控页**: 新增"姿态控制"卡片，蹲下（100°）/ 起立（40°）/ 跳舞（1Hz 交替）
- **独立姿态页** `pages/pose`: 蹲下 / 起立 / 跳舞，跳舞频率可调（滑块），停止时回到标准站姿
- 入口在遥控页姿态卡片右下角的"姿态页"链接

#### 2. 横滚角 (Roll) 姿态补偿
- **新模块** `hardware/roll_compensator`: 按 Roll 角调整左右腿长度，适应左右高度不同的地面
- **策略**: 站立时高侧收腿（角度↑），蹲下时低侧伸腿（角度↓），单侧限幅 25°
- **仅在起立状态生效**（`servo_set_balance_mode()`），蹲下 / 遥控 / 停止时不补偿
- **默认关闭**（增益 0），死区 10°，需要实测确认方向后再开

#### 3. 姿态角解算重构
- **pitch**: `atan2(ay, az)`，水平时自动为 0，不再需要 90° 基准
- **roll**: `atan2(ax, az)`，加速度计融合权重提高到 10%（pitch 保持 2%，控制环需要稳定）
- 输出结构体 / 脱机记录新增 roll 字段

#### 4. 状态灯自动配色
- **新模块** `user/status_led`: 按车体状态自动设置 SK6812 颜色
- 优先级（高→低）：摔倒红 > 舵机转动粉 > 合体蓝 > 未对齐红 > 对接中闪黄 > 站立绿 > 未站立的黄
- App / LCD 手动设色后保持用户颜色，直到下一次状态切换才交还自动配色

#### 5. LCD 与配平
- **主页**: 新增 Roll 行，版本号行下移；MPU 页显示 R/P/Y 三轴
- **配平**: 同时采 pitch 和 roll 零点（NVS 键 `bal_zero_p` / `bal_zero_r`）

#### 6. 参数
- **参数版本 38**（与 App 同步）
- **舵机中心角默认值**: 80°→100°
- 新增 `servo_height_table.h`（舵机角度 ↔ 底盘高度对照表，待实测填表）

#### 7. 脱机记录格式
- `trace_sample_t` 新增 `roll` 字段，每条 **68→72 字节**
- `scripts/read_flash_log.py`、`scripts/capture_trace.py` 同步（CSV 新增 roll 列）

### 测试
- `scripts/run_tests.sh 0.43` 55 项全过，参数表 24 项一致
- `0.43/main_car`、`0.43/sub_car` 编译通过，固件版本号 0.43.0

### 升级说明
1. 烧录 `0.43/main_car` 固件（副车如需同步烧 `0.43/sub_car`）
2. App 需重新打包（参数版本 38 + 姿态页）
3. 建议点"恢复默认"让新默认参数生效（舵机中心角变 100°）
4. Roll 补偿默认关闭，确认 Roll 正负方向后再启用

## v0.42 (2026-11-01)

**三问题联动修复：站立晃动 + 蓝牙连接 + LCD刷新**

### 主要改进

#### 1. 站立时移动晃动 + 往前走摆回来
- **LQR 增益提升**: KP 18→22, KD 0.5→0.6, VMAX 30→35 cm/s
  - 位置保持更紧，回位更快，站立更稳
- **速度环提速**: 斜坡加速 60→150 rpm/s, 减速 120 rpm/s
  - spd_kp 0.06→0.08, spd_ki 0.01→0.04
  - 档位目标 move_rpm_max 100→120 rpm
  - 方向键响应更快，跟随性更好
- **倾角/电机放开**: 
  - 电机输出上限 60→95%
  - 倾角限制 25→35°
  - 起立软启动 15%/1500ms → 30%/800ms
  - 大角度误差时有更强的拉回能力

#### 2. 蓝牙刚开机能连，等一会儿就连不上
- **根因**: NimBLE 主机任务默认优先级低于 WiFi，开机后 WiFi/MQTT 活动时 BLE 广播重启被挤占
- **修复**: 
  - BLE 任务优先级提到 23 (高于 WiFi 默认 5)
  - 广播参数优化 (itvl 100~200ms)
  - 开机后 10 秒仍可正常连接

#### 3. LCD 刷新慢
- **刷新周期**: 150ms → 50ms
- **增量更新**: 只重画变化的行（字符串缓存比对）
- **实时性提升**: 姿态角/轮速等数据刷新更流畅

### 参数版本
- 参数表版本 37（与 App 同步）
- 24 项参数默认值已调整，建议"恢复默认"

### 技术细节
- **位置积分上限**: 3→5°
- **位置环倾角上限**: 5→8°
- **速度环倾角上限**: 4→7°
- **测试验证**: `run_tests.sh` 55 项全过，`check_param_sync.py` 24 项一致

### 升级说明
1. 烧录 `0.42/main_car` 固件

3. 建议点击"恢复默认"让参数生效

## v0.41 (2026-10-31)

**双车对接 + 蓝牙直控 + 状态页双车显示**

### 主要功能

#### 1. 双车架构
- **目录结构**: `main_car/`（主车固件）、`sub_car/`（副车固件）
- **OneNET 设备**: 
  - 主车: balancing_dog (原设备)
  - 副车: balancing_dog_sub (设备 ID 2688649600)
- **App 控制方式**: 合体模式 / 主车 / 副车
- **对接检测**: PCF8574 的 P4/P5 微动开关

#### 2. 蓝牙直控（BLE）
- **广播名**: 主车 BalanceDog，副车 BalanceDogSub
- **协议**: 移动指令 `M:<speed>`、急停 `STOP`、起立 `STAND`
- **pitch 通知**: 连接后每 100ms 推送当前 pitch 值
- **链路选择**: 连着蓝牙的车，移动/急停/起立走蓝牙，其余走 OneNET
- **内存优化**: 
  - BLE 先于 WiFi 启动
  - NimBLE/mbedTLS 缓冲放 PSRAM
  - WiFi 静态缓冲 10/16 → 6/6

#### 3. 状态页双车显示
- **Pitch 曲线**: 主车绿线、副车蓝线，同屏显示
- **实时状态对照表**: 链路、数据间隔、姿态、轮速、遥控指令，主副车两列
- **离线判定**: 3 秒没数据算离线
- **轮询策略**: 常规属性两车轮流（各约 400ms），pitch 历史各 120ms

#### 4. LCD 同步优化
- 舵机页、主页的舵机角随 App 操作实时刷新
- App 起立成功后 LCD 自动切到平衡页
- 平衡页进入时不再强制停机

#### 5. 急停退页
- App 急停 → 车端 `remote_stop()`
- LCD 在平衡页时自动退回主页

### 参数版本
- 参数表版本 35（与 App 同步）

### 技术细节
- **连接页**: 删除"项目 ID"输入框（OneNET API 不再需要）
- **tabBar**: 只保留"遥控"和"状态"两个入口
- **配平物模型**: 需在 OneNET 后台按 `onenet_物模型_补充.md` 添加 4 个 `trim_*` 服务

### 升级说明
1. 副车首次烧录后需在 OneNET 后台确认设备已激活
2. App 需重新打包（状态页双车显示）
3. 合体模式待对接硬件验证
