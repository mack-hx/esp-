## v0.2 (2026-10-21)

- **三端打通里程碑**: App ↔ OneNet ↔ 小车 全链路实测通过

## v0.17 (2026-10-21)

### 设备端
- 修 4 个 bug: 服务应答随机丢失 (static 缓冲区没截断)、属性上报 step 不对齐整帧被拒、
  事件参数单位错误、平台拒收日志刷屏
- 属性上报按 step 分帧 (角度帧 / 角速度帧 / 整数帧 / 字符串帧)
- 新增上报: 灯 / 电磁铁 / 舵机角度 / 开关状态, 1s 一帧
- 移动指令同时认 `speed` (物模型里真实存在的) 和 `vx`

### App 端
- 移动指令从 `{vx, w}` 改成 `{speed}` (物模型里根本没有 `vx` / `w`)
- 统一错误出口: 单条指令失败不再把整条连接判成"错误"
- 平台返回 `code != 0` 一律抛异常 (以前 10415 被当成成功)
- 浏览器刷新后自动重连
- 参数表跟设备端 `param.c` 逐项对齐 (原来 6 项对不上)
- 删掉状态页里那份重复的 PID 编辑器

### 平台侧
用户在 OneNet 后台补齐物模型: 灯 / 电磁铁 / 舵机 / 开关 / `param_get` / `param_set` /
`param_save`。还差一项: `param_set` 的输出参数是空的。

### 代码整理
- 删掉 7MB 无引用的 OneNET SDK 备份 + 3 个旧 MQTT 文件 + 5.5MB clangd 索引
- 修正一批过期文档 (README / 物模型指南 / 注释里写反的 AccessKey 说明)

### 编译信息
- RAM: 13.8% (45,308 / 327,680)
- Flash: 27.6% (1,014,605 / 3,670,016)
