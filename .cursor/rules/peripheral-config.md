# 外设配置说明

本文档详细说明机械狗项目中使用的所有外设模块的配置信息、通信协议和驱动要求。

---

## 1. MPU9250 九轴惯性测量单元 (IMU)

### 基本信息
- **型号**: MPU9250
- **功能**: 三轴加速度计 + 三轴陀螺仪 + 三轴磁力计
- **通信接口**: I2C
- **I2C 地址**: 0x68 (默认) 或 0x69 (可选)

### 引脚连接
- **SCL1** (GPIO1): I2C 时钟线
- **SDA1** (GPIO2): I2C 数据线
- **INT** (GPIO3): 数据就绪中断输出

### 功能说明
- 用于检测机械狗的姿态角度、角速度和加速度
- 为平衡控制算法提供实时反馈数据
- 中断引脚用于通知新数据可读

### 驱动要求
- 初始化 I2C 总线 (400kHz)
- 配置加速度计量程 (±2g/±4g/±8g/±16g)
- 配置陀螺仪量程 (±250°/s ~ ±2000°/s)
- 配置数据更新率 (1kHz 推荐)
- 实现中断服务程序读取数据
- 实现姿态解算算法 (互补滤波/卡尔曼滤波)

## 2. 74HC595D 串行移位寄存器

### 基本信息
- **型号**: 74HC595D
- **功能**: 8 位串行输入并行输出移位寄存器
- **通信接口**: SPI (软件模拟)
- **输出能力**: 8 个数字输出引脚

### 引脚连接
- **SCLK** (GPIO4): 串行时钟 (Shift Clock)
- **RCLK** (GPIO5): 锁存时钟 (Latch Clock)
- **DS** (GPIO6): 串行数据输入 (Data Serial)

### 输出分配
| 输出 | 功能 | 输入值 | 连接设备 |
|------|------|--------|----------|
| Q0 | 悬空 |  | (无, 保留) |
| Q1 | AIN1 | TB6612 电机 A 方向 1 | TB6612 |
| Q2 | AIN2 | TB6612 电机 A 方向 2 | TB6612 |
| Q3 | BIN1 | TB6612 电机 B 方向 1 | TB6612 |
| Q4 | BIN2 | TB6612 电机 B 方向 2 | TB6612 |
| Q5 | IO1 | 电磁铁1 控制 | 电磁铁1 |
| Q6 | IO2 | 电磁铁2 控制 | 电磁铁2 |
| Q7 | 保留 | 未使用 | - |

### 功能说明
- 扩展 ESP32 的 GPIO 输出能力
- 控制 TB6612 电机驱动的方向引脚
- 控制两个电磁铁的开关
- Q0 保留为通用输出, 可作为未来扩展

### 驱动要求
- 实现软件 SPI 时序
- 提供位操作函数设置单个输出
- 提供字节操作函数设置所有输出
- 锁存功能确保输出同步更新

## 3. 128×160 RGB TFT 显示屏

### 基本信息
- **分辨率**: 128 × 160 像素
- **颜色**: RGB 65K 色
- **驱动芯片**: ST7735 / ST7789 (常见)
- **通信接口**: SPI

### 引脚连接
- **SCL2** (GPIO7): SPI 时钟线
- **SDA2** (GPIO8): SPI 数据线 (MOSI)
- **DC** (GPIO10): 数据/命令选择
- **CS** (GPIO11): 片选信号
- **BLK** (GPIO12): 背光控制 (PWM)

### 复位处理
- TFT 模块 RST 引脚已短接 VCC
- 上电依赖模块内部 Power-On-Reset (POR) 复位
- 驱动器不做软件复位操作 (在 tft_hard_reset 已移除)

### 功能说明
- 显示机械狗状态信息
- 显示传感器数据
- 显示电池电压
- 显示运行模式

### 驱动要求
- 初始化 SPI 总线 (10~40 MHz)
- 实现屏幕初始化序列
- 实现基本图形绘制函数 (点、线、矩形、圆)
- 实现字符/字符串显示
- PWM 控制背光亮度

## 4. 舵机控制

### 基本信息
- **数量**: 2 个
- **类型**: 标准 PWM 舵机
- **控制信号**: PWM (50Hz, 1~2ms 脉宽)

### 引脚连接
- **PWM1** (GPIO13): 舵机1 控制信号
- **PWM2** (GPIO14): 舵机2 控制信号

### 功能说明
- 舵机1: 机械狗头部转向
- 舵机2: 机械狗其他关节控制

### 驱动要求
- 使用 ESP32 LEDC PWM 外设
- 配置 50Hz 频率 (20ms 周期)
- 脉宽范围 1~2ms (对应 0°~180°)
- 提供角度到脉宽的转换函数

---

## 5. TB6612FNG 电机驱动

### 基本信息
- **型号**: TB6612FNG
- **功能**: 双路直流电机驱动
- **输出电流**: 1.2A (连续) / 3.2A (峰值)
- **工作电压**: 2.7V ~ 13.5V

### 引脚连接
- **PWMA** (GPIO15): 电机 A PWM 速度控制
- **PWMB** (GPIO16): 电机 B PWM 速度控制
- **AIN1** (74HC595 Q1): 电机 A 方向控制 1
- **AIN2** (74HC595 Q2): 电机 A 方向控制 2
- **BIN1** (74HC595 Q3): 电机 B 方向控制 1
- **BIN2** (74HC595 Q4): 电机 B 方向控制 2

### 真值表
| AIN1 | AIN2 | 电机 A 状态 |
|------|------|-------------|
| 0 | 0 | 短路制动 |
| 0 | 1 | 正转 |
| 1 | 0 | 反转 |
| 1 | 1 | 短路制动 |

### 功能说明
- 驱动机械狗的两个轮子
- 支持速度和方向独立控制
- 配合编码器实现闭环控制

### 驱动要求
- 使用 ESP32 LEDC PWM 外设
- 配置 PWM 频率 (1kHz ~ 20kHz)
- 通过 74HC595 控制方向引脚
- 提供前进/后退/转向控制函数

## 6. PCF8574 I2C IO 扩展芯片

### 基本信息
- **型号**: PCF8574
- **功能**: 8 位 I2C IO 扩展
- **I2C 地址**: 0x20 ~ 0x27 (可配置)

### 引脚连接
- **SCL3** (GPIO17): I2C 时钟线
- **SDA3** (GPIO18): I2C 数据线
- **INT2** (GPIO21): 中断输出 (低电平有效)

### IO 分配
| 引脚 | 功能 | 说明 |
|------|------|------|
| P0 | K1 | 按键1 (下拉输入) |
| P1 | K2 | 按键2 (下拉输入) |
| P2 | K3 | 按键3 (下拉输入) |
| P3 | K4 | 按键4 (下拉输入) |
| P4 | K6 | 微动开关2 (下拉输入) |
| P5 | K5 | 微动开关1 (下拉输入) |
| P6 | 保留 | 未使用 |
| P7 | 保留 | 未使用 |

### 功能说明
- 扩展按键输入
- 检测微动开关状态
- 中断引脚用于按键按下检测

### 驱动要求
- 初始化 I2C 总线
- 实现按键扫描函数
- 实现中断服务程序
- 实现按键消抖算法

- **通信接口**: UART
- **波特率**: 115200 bps (可配置)

### 引脚连接
- **TXD1** (GPIO38): UART 发送 (ESP32 → K230)

### 功能说明
- 与 K230 AI 处理器通信
- 接收视觉识别结果
- 发送控制指令

### 驱动要求
- 初始化 UART1 (115200, 8N1)
- 实现数据收发缓冲区
- 定义通信协议 (帧头、数据、校验)
- 实现协议解析和封装函数

## 10. SK6812 RGB LED

### 基本信息
- **型号**: SK6812
- **功能**: 可编程 RGB LED
- **通信协议**: 单线串行通信 (NRZ)
- **颜色**: 24 位 RGB (16M 色)
- **时序参数** (来自 datasheet):
  - T0H (0码高电平): 0.3µs ± 0.15µs
  - T0L (0码低电平): 0.9µs ± 0.15µs
  - T1H (1码高电平): 0.6µs ± 0.15µs
  - T1L (1码低电平): 0.6µs ± 0.15µs
  - 复位码: >80µs 低电平

### 引脚连接
- **DIN** (GPIO9): 由 ESP32 RMT 外设直接驱动
  - 历史变更: 原接 74HC595 Q0 (只能开关, 无法调色)
  - 现为 ESP32 直驱, 支持 RGB 完整控制

### 功能说明
- 指示机械狗运行状态
- 支持呼吸灯、流水灯等效果
- 真实调色调光 (R/G/B 任意比例)

### 驱动要求
- 使用 ESP32 RMT TX 外设
- RMT 时钟源: 10MHz (100ns 精度)
- 使用 LED 编码器 (led_strip_encoder) 自动生成时序
- 提供颜色设置函数 (RGB)
- 提供亮度调节函数
- 提供动画效果函数

## 外设优先级和初始化顺序

### 初始化顺序建议
1. **74HC595** - 先初始化,设置所有输出为安全状态
2. **MPU9250** - IMU 传感器,需要时间稳定
3. **编码器 (PCNT)** - 配置脉冲计数器
4. **TB6612 (PWM)** - 电机驱动 PWM 初始化
5. **舵机 (PWM)** - 舵机 PWM 初始化
6. **TFT 屏幕** - 显示初始化信息
8. **K230 UART** - 视觉通信
9. **CI-03T UART** - 语音识别
10. **SK6812 LED (RMT)** - 状态指示 (可在任意时机调用)

### 实时性要求
- **高优先级**: MPU9250 (姿态控制回路 1kHz)
- **中优先级**: 编码器读取 (速度控制 100Hz)
- **低优先级**: 显示刷新、按键扫描 (10Hz)

---

## 注意事项

1. **电源管理**: 舵机、电机、电磁铁需要独立供电,与主控共地
2. **电磁兼容**: 电机、电磁铁可能产生干扰,需加滤波电容
3. **信号完整性**: I2C 总线建议加上拉电阻 (4.7kΩ)
4. **中断优先级**: MPU9250 中断优先级应最高
5. **看门狗**: 建议启用硬件看门狗防止程序跑飞
6. **RMT 通道冲突**: SK6812 使用 RMT 通道 0, 不要与其他红外/无线应用共用
